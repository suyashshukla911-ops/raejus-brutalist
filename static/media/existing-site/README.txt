ORIGINAL-ASSET PRESERVATION
===========================

Place the existing RAEJUS site images/videos/files here exactly as exported from the current site.

Recommended subfolders:
  profile/
  media/
  books/
  videos/

Do not recompress, recolor, resize, or rename the source assets if the requirement is strict 1:1 preservation.

The new SvelteKit UI intentionally treats these as source assets. No generated replacement artwork is substituted for the original media.
